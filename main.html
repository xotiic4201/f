🤖 Bot Management

💻 Remote Terminal

Execute system commands on remote bots:

  • dir - List directory (Windows)
  • ls -la - List directory (Linux/Mac)
  • whoami - Current user
  • ipconfig / ifconfig - Network info
  • ps aux - Running processes
⚡ DDoS Attacks

HTTP Flood: Sends HTTP GET requests to target website.

SYN Flood: TCP SYN packets (requires raw socket - root/admin).

UDP Flood: Sends UDP packets to target port.
